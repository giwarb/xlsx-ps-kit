- 内容: 「やったこと」には起動前後の `Get-Process EXCEL` 差分で PID を特定すると残っています。後段のレビュー対応記録と実装は `Application.Hwnd` 方式へ正しく更新されているため、安全性への影響はありませんが、引き継ぎ時に誤解を招きます。

```markdown
- `Start-XlsApplication -Visible`: `Application.Hwnd` を
  `GetWindowThreadProcessId` で PID に変換し、プロセス名と開始時刻を記録して返す。
```
