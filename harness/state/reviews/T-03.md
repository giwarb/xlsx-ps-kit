## 指摘

### [blocking] テスト準備の直接COM操作はG-06の読み替え対象にならない

- 場所: `tests/Invoke-XlsSession.Tests.ps1:14`、`tests/Invoke-XlsSession.Tests.ps1:40`、`tests/Invoke-XlsSession.Tests.ps1:93`
- 内容: `New-TestWorkbookFile` が `Workbooks.Add`、`SaveAs`、`Close`、`ReleaseComObject` を直接実行し、ロック保持側も `Workbooks.Open` 以降を直接操作しています。G-06は「テストコードも同様」と明記しており、T-02の読み替えは `Invoke-XlsSession` が未実装だったための一時措置です。実際に `tests/T02.Tests.ps1:10` も「T-03以降は厳格適用」としています。したがって、内部ヘルパーが安全であることや前提条件の準備であることは、T-03での例外を正当化しません。また、テスト内の定数 `51` の直書きはQ-3も満たしません。
- 修正案: 保存済みの小さな `.xlsx` をテストfixtureとして用意し、別のSTA runspaceから公開関数 `Invoke-XlsSession` を呼んでロックを保持してください。同期オブジェクトでロック成立と解除を制御すれば、すべてのCOM操作をScriptBlock内に収められます。

```powershell
# 別STA runspace側
Import-Module $modulePath -Force
Invoke-XlsSession -Path $fixturePath -ScriptBlock {
    param($app, $wb)
    $ready.Set()
    $release.Wait()
}

# 親側は $ready.Wait() 後に同じfixtureを開き、ReadOnly例外を検証する。
# finallyで $release.Set()、EndInvoke、PowerShell/RunspaceをDisposeする。
```

### [should-fix] S-3で指定されたQuitとReleaseの順序になっていない

- 場所: `skill/scripts/XlsAgent.psm1:307`、`skill/scripts/XlsAgent.psm1:316`、`skill/scripts/XlsAgent.psm1:320`
- 内容: 設計とチェックリストは `Workbook.Close` → `Application.Quit` → 子から親への `ReleaseComObject` → GC×2です。現状はWorkbookをReleaseしてから `Stop-XlsApplication` 内でQuitしているため、指定順序を満たしません。
- 修正案: `Stop-XlsApplication` に任意のWorkbook引数を追加するなどして、Quit後にWorkbook、Applicationの順でReleaseし、最後にGC×2を行ってください。各解放が例外でも後続処理へ進むよう、入れ子のfinallyにします。

```powershell
try {
    $Application.Quit()
}
finally {
    try {
        if ($Workbook -and [Runtime.InteropServices.Marshal]::IsComObject($Workbook)) {
            [void][Runtime.InteropServices.Marshal]::ReleaseComObject($Workbook)
        }
    }
    finally {
        try {
            if ([Runtime.InteropServices.Marshal]::IsComObject($Application)) {
                [void][Runtime.InteropServices.Marshal]::ReleaseComObject($Application)
            }
        }
        finally {
            [GC]::Collect()
            [GC]::WaitForPendingFinalizers()
            [GC]::Collect()
            [GC]::WaitForPendingFinalizers()
        }
    }
}
```
