### [should-fix] stale cache と `-Force` の対比だけでは refused 側の未再計算を証明できない

- 場所: `tests/Test-XlsFormulas.Tests.ps1:528`、`harness/state/tasks/T-11.md:94`
- 内容: refused 呼び出しは ReadOnly セッションを閉じるため、仮に誤って `CalculateFullRebuild` を実行してから refused を返しても、再計算結果は保存されません。その後の `-Force` はディスク上の同じ stale fixture を新しいセッションで開くので、現在のテスト結果はその誤実装でも同じになります。キー集合の検査も戻り値の形だけを保証し、再計算や走査が実行されなかったことは保証しません。現行コード自体は `skill/scripts/XlsAgent.psm1:3162` の早期 return が `Set-XlsCalculationAutomatic`（同:3176）より前なので正しいです。
- 修正案: テスト名とコメントの証明範囲を正確にし、未再計算はコード順序のレビューで確認したことを明記する。実行可能な回帰保証が必要なら、fixture作成後の refused 呼び出しについて `Set-XlsCalculationAutomatic` の行が未到達であることをコードカバレッジ等で直接計測する。

```diff
-It '-Force skips the refused check and performs a real recalculation, ... (proves refused truly skips CalculateFullRebuild)' {
+It '-Force skips the refused check and performs a real recalculation, revealing a stale-cache error' {
@@
-# 「-Force で初めて古いキャッシュの誤りが露見する」ことが refused の未再計算を実証する。
+# この対比は -Force が CalculateFullRebuild に到達することを確認する。
+# refused 側の未再計算は、早期 return が Set-XlsCalculationAutomatic より前にあるコード順序で確認する。
```

### [nit] 「全リンクを返す」判断を mixed-link fixture で固定していない

- 場所: `skill/scripts/XlsAgent.psm1:3053`、`tests/Test-XlsFormulas.Tests.ps1:456`
- 内容: `links` に存在するものも含めた全リンクを返す判断は妥当です。設計は missing-only を要求しておらず、`Get-XlsModel.workbook.links` との意味の統一と診断情報の完全性にも利点があります。ただし現テストは「missing 1件」と「existing 1件」を別々に検証しており、existing と missing が混在した refused で両方が返ることを固定していません。
- 修正案: 混在fixtureを1件追加し、refused と全2パスの集合を検査する。

```powershell
$result.status | Should Be 'refused'
$result.links.Count | Should Be 2
(($result.links | Sort-Object) -join '|') |
    Should Be ((@($existingPath, $missingPath) | Sort-Object) -join '|')
```
