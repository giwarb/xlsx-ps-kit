## 指摘

### [should-fix] JSONテストがキー集合と単一要素配列の形を固定していない

- 場所: `tests/Test-XlsFormulas.Tests.ps1:344`
- 内容: `-AsJson` テストは必須キーへアクセスしているが、トップレベル／summaryの正確なキー集合を比較していない。また `@($parsed...locations)` は、`locations` がJSON配列ではなく単一文字列に退行しても同じ結果になる。現在の実装は正しい形を生成しているが、G-04の「キー名と形」を回帰テストで完全には固定できていない。
- 修正案:

```powershell
(($parsed.PSObject.Properties.Name | Sort-Object) -join ',') |
    Should Be 'error_summary,status,total_errors,total_formulas'

$summary = $parsed.error_summary.'#DIV/0!'
(($summary.PSObject.Properties.Name | Sort-Object) -join ',') |
    Should Be 'count,locations,locations_truncated'

($summary.locations -is [System.Array]) | Should Be $true
$summary.locations.Count | Should Be 1
$summary.locations[0] | Should Be 'Sheet1!A1'
```

### [should-fix] stale cacheフィクスチャの読み取り文字コードが暗黙

- 場所: `tests/Test-XlsFormulas.Tests.ps1:169`、`tests/Test-XlsFormulas.Tests.ps1:185`、`tests/Test-XlsFormulas.Tests.ps1:190`
- 内容: OOXMLの `sheet1.xml`、`[Content_Types].xml`、`workbook.xml.rels` を `Get-Content -Raw` で読み、PowerShell 5.1の既定文字コードに依存している。内容は通常ASCII主体なので現テストへの影響は小さいが、S-01／P-3の「ファイルI/OはUTF-8明示」に一致しない。
- 修正案:

```powershell
$sheetXml = Get-Content -LiteralPath $sheetPath -Raw -Encoding UTF8
$ct = Get-Content -LiteralPath $ctPath -Raw -Encoding UTF8
$rels = Get-Content -LiteralPath $relsPath -Raw -Encoding UTF8
```
