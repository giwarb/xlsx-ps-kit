## 指摘

### [should-fix] 座標なしテストが通常の A1 座標を見逃す
- 場所: `tests/Get-XlsOverview.Tests.ps1:126`
- 内容: `'\$[A-Z]{1,3}\$?\d+'` は先頭の `$` を必須にしているため、設計が例示する `A1` や `A$1` を検出しない。実装自体は座標を生成していないが、将来の回帰を防げない。
- 修正案:

```powershell
$out | Should Not Match '(?<![A-Za-z0-9_])\$?[A-Z]{1,3}\$?\d+(?![A-Za-z0-9_])'
```

### [should-fix] Get-XlsOverview 経由のファイル不在テストがない
- 場所: `tests/Get-XlsOverview.Tests.ps1:229`
- 内容: チェックリスト T-5 が挙げる異常系のうち、本関数に直接関係するファイル不在が未検証。`-ReadOnly` で Excel 起動後に例外となるため、公開関数経由で後始末まで確認する価値がある。
- 修正案:

```powershell
It 'throws a next-step error and leaves no Excel process when the file does not exist' {
    $path = New-TempXlsxPath
    $errorSeen = $null

    try {
        Get-XlsOverview -Path $path
    }
    catch {
        $errorSeen = $_
    }

    $errorSeen | Should Not Be $null
    $errorSeen.Exception.Message | Should Match 'File not found'
}
```

`AfterEach` の `Assert-NoOrphanExcel` がプロセス残留も検証する。
