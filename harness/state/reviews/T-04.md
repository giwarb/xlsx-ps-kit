## 指摘

### [blocking] 単一セルへの scalar `Value2` 代入も G-08 違反
- 場所: `tests/Save-XlsWorkbook.Tests.ps1:196,214,219,290,295`、`harness/state/tasks/T-04.md:142`
- 内容: G-08 は「`Range.Value2` への代入は `[object[,]]` のみ」としており、単一セルの例外は定めていない。新規テストは文字列・数値を直接代入しているため、自己チェックの○と一致しない。
- 修正案:

```powershell
[object[,]]$cellData = [Array]::CreateInstance([object], 1, 1)
$cellData[0, 0] = $marker
$ws.Range('A1').Value2 = $cellData
```

同じ形で `'first'`、`'second'`、`10`、`99` の代入も `[object[,]]` にする。

### [should-fix] Automatic 切替から状態復元までを同じ try/finally に入れる
- 場所: `skill/scripts/XlsAgent.psm1:513-533`、`tests/Save-XlsWorkbook.Tests.ps1:282`
- 内容: 保存後に Manual へ戻す設計判断自体は妥当で、Automatic がファイルへ焼き込まれた後にライブセッションだけ Manual へ戻しても受け入れ条件を損なわない。ただし `Set-XlsCalculationAutomatic` とパス判定が `try` の外にあるため、`CalculateFullRebuild()` や COM プロパティ取得が例外になると Manual へ戻らない。また、`Save`/`SaveAs` の失敗は生の COM エラーになり、S-04を満たさない。
- 修正案:

```powershell
$app = $Workbook.Application

try {
    Set-XlsCalculationAutomatic -Application $app

    $currentFullName = $null
    if ($Workbook.Path) {
        $currentFullName = $Workbook.FullName
    }

    $sameFile = Test-XlsSamePath -PathA $currentFullName -PathB $Path
    if ($sameFile) {
        $Workbook.Save()
    }
    else {
        $targetFullName = (New-Object IO.FileInfo($Path)).FullName
        $Workbook.SaveAs($targetFullName, $fileFormat)
    }
}
catch {
    throw "Failed to recalculate or save workbook to '$Path'. Check the parent directory, permissions, file locks, and extension. Excel reported: $($_.Exception.Message)"
}
finally {
    $app.Calculation = $script:Xl.xlCalculationManual
}
```

存在しない親ディレクトリ等で `SaveAs` を失敗させ、エラーが行動可能な内容であることと、catch 後の `$app.Calculation` が Manual であることもテストする。

### [should-fix] OOXML テストの文字エンコーディングを明示する
- 場所: `tests/Save-XlsWorkbook.Tests.ps1:85`
- 内容: `StreamReader($stream)` は実質UTF-8既定だが、S-01/P-3はファイルI/Oのエンコーディング明示を求めている。
- 修正案:

```powershell
$reader = New-Object -TypeName System.IO.StreamReader `
    -ArgumentList @($stream, [Text.Encoding]::UTF8, $true)
```
