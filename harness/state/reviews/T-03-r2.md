## 指摘

### [blocking] テストfixture作成がG-09の保存経路を迂回している

- 場所: `tests/Invoke-XlsSession.Tests.ps1:47`
- 内容: `$wb.SaveAs($Path, $xlOpenXMLWorkbook)` は `Invoke-XlsSession` のScriptBlock内に移されたため、round 1のG-06違反は解消しています。しかし、G-09は「保存は `Save-XlsWorkbook` のみ」と定めており、テスト準備にも直接 `SaveAs` を許す例外はありません。T-04が未実装であることは、保存経路を迂回する理由にはできません。
- 修正案: 保存済みの小さな `.xlsx` を `tests/fixtures/blank.xlsx` などへfixtureとして追加し、ReadOnly・ロックテストではそのfixtureを直接使ってください。これにより `New-TestWorkbookFile`、直接 `SaveAs`、T-03での `xlOpenXMLWorkbook` 追加を削除できます。

```powershell
$fixturePath = Join-Path $here 'fixtures\blank.xlsx'

It '(b) throws a read-only error when another process already has the file open' {
    $path = $fixturePath
    # 以降は現在の別STA runspace＋Invoke-XlsSessionによるロック保持を使用
}

It 'opens an existing file read-only without throwing when -ReadOnly is requested explicitly' {
    $readOnlySeen = Invoke-XlsSession -Path $fixturePath -ReadOnly -ScriptBlock {
        param($app, $wb)
        $wb.ReadOnly
    }

    $readOnlySeen | Should Be $true
}
```
