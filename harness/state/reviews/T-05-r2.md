## 指摘

### [should-fix] 回収側の排他リースを停止処理の完了まで保持する

- 場所: `skill/scripts/XlsAgent.psm1:898`、`skill/scripts/XlsAgent.psm1:937`、`skill/scripts/XlsAgent.psm1:954`
- 内容: `$orphanLease` は読み取りと最初の所有権判定が終わった時点で解放され、`ShouldProcess`、停止直前の再検証、`Stop-Process`、終了待機はリースなしで実行されます。この間、別の `Clear-XlsOrphans` が同じマーカーを取得して同じ停止処理へ進めるため、二重停止やマーカー削除競合による不定な結果・例外が起こり得ます。同じProcessオブジェクトの再検証と `-InputObject` によりPID再利用先を停止する問題は解消されているため、G-10違反の blocking ではありません。
- 修正案: 排他リース内で読み取り、判定、`ShouldProcess`、再検証、停止、`WaitForExit` まで行い、`finally` でリースを解放してから、必要なマーカー削除を行ってください。

```powershell
try {
    # マーカー読み取り、所有権判定

    if ($action -eq 'ConfirmedOwned' -and
        $PSCmdlet.ShouldProcess("EXCEL.EXE (PID $markerPid)", 'Stop-Process')) {
        $process.Refresh()
        # HasExited / ProcessName / StartTime を再検証
        Stop-Process -InputObject $process -Force -ErrorAction Stop
        if (-not $process.WaitForExit(5000)) {
            throw "Owned EXCEL.EXE PID $markerPid did not terminate within 5 seconds."
        }
        $action = 'Stopped'
    }
}
finally {
    $orphanLease.Dispose()
}

# リース解放後、Actionに応じてマーカーを削除または保持する
```
