## 指摘

### [blocking] `Set-XlsRange` の必須択一シグネチャが未実装

- 場所: skill/scripts/XlsAgent.psm1:201
- 内容: 設計 §3.5 は `-Data`、`-FromCsv`、`-FromJson` のいずれか一つを必須としています。現状はすべて任意かつ同じ `__AllParameterSets` に属するため、入力元なしや複数指定がパラメーターバインドを通過します。関数シグネチャの契約逸脱です。
- 修正案:

```powershell
[CmdletBinding()]
param(
    [Parameter(Mandatory = $true)]
    $Worksheet,

    [Parameter(Mandatory = $true)]
    [string]$Range,

    [Parameter(Mandatory = $true, ParameterSetName = 'ByData')]
    [object[,]]$Data,

    [Parameter(Mandatory = $true, ParameterSetName = 'ByCsv')]
    [string]$FromCsv,

    [Parameter(Mandatory = $true, ParameterSetName = 'ByJson')]
    [string]$FromJson,

    [switch]$Header
)
```

### [should-fix] スタブのテスト名とアサーションが一致しない

- 場所: tests/T01.Tests.ps1:72
- 内容: テスト名は各スタブが throw するとしていますが、実際のアサーションは `Get-Command` が `$null` でないことだけです。これは直前の Export テストと重複し、関数本体が空になっても通過します。
- 修正案:

```powershell
It "stub function '$fn' contains an explicit throw" {
    Import-Module $modulePath -Force
    $cmd = Get-Command $fn -Module $moduleName
    $throwAst = $cmd.ScriptBlock.Ast.Find(
        {
            param($node)
            $node -is [System.Management.Automation.Language.ThrowStatementAst]
        },
        $true
    )
    $throwAst | Should Not Be $null
}
```

PowerShell 5.1向けの BOM、`#Requires`、コメントベースヘルプが揃い、設計上の実体である公開 8 関数も過不足なく Export されています。PID ベースラインを `BeforeEach`、残骸検査を `AfterEach` に置いた構成も今後のテストで継続してください。
