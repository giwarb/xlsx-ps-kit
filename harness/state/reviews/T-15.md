## 指摘

### [blocking] `Invoke-XlsSession` の呼び出し例が必須シグネチャを満たさない
- 場所: skill/SKILL.md:9
- 内容: `XlsAgent.psm1:357-366` では `Path` と `ScriptBlock` がともに必須だが、冒頭表は `Invoke-XlsSession { param(...) ... }` としており、有効な呼び出しにならない。タスクの「記載された関数シグネチャを実装と一致させる」に反する。
- 修正案:

```markdown
| **Create** or **edit** with formulas/formatting | Excel COM inside `Invoke-XlsSession -Path file.xlsx -ScriptBlock { param($app,$wb) ... }` — see gotchas below |
```

### [blocking] `refused` を通常の検証結果と同じ JSON 形状に見せている
- 場所: skill/SKILL.md:39
- 内容: 現文は `status` が `refused` の場合にも `total_formulas`、`total_errors`、`error_summary` が返るように読める。実装は `XlsAgent.psm1:3199-3203` の `{status, reason, links}` と、同 `3262-3267` の通常形状を明確に分けている。後段で `links` を説明しても、通常キーが存在しないことは示せていない。
- 修正案:

```markdown
For `success` or `errors_found`, JSON contains `status`, `total_formulas`, `total_errors`, and `error_summary` ... A refused run instead returns only `status: "refused"`, `reason`, and `links`; it does not contain formula or error totals.
```

### [blocking] CSV の型変換説明が `Set-XlsRange -FromCsv` の実装と逆
- 場所: skill/SKILL.md:72
- 内容: 「CSV round-trips every value as a string」「dates and numbers lose their type」とあるが、`XlsAgent.psm1:2680-2730` は空文字列を `$null`、厳密な `True`/`False` を bool、不変カルチャの数値を `[double]` に型推論し、ISO 日付は後段でシリアル値へ変換する。実際の制約は、CSV に元型情報がないため `"42"` のような文字列セルが数値化され得ること。
- 修正案:

```markdown
- **CSV does not preserve the original cell type metadata.** `Set-XlsRange -FromCsv` infers empty fields as `$null`, exact `True`/`False` as booleans, invariant-culture numbers as `[double]`, and exact emitted ISO dates as dates. Consequently, text that merely looks numeric (for example `"42"`) may round-trip as a number. `-Header` has no effect with `-FromCsv`.
```
