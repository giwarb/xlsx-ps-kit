# T-05 Clear-XlsOrphans

## 目的
クラッシュ等で残った「自モジュールが起動した」EXCEL.EXE だけを回収する `Clear-XlsOrphans` を実装する。

> 02-implementation-plan.md: 「孤児プロセス回収 `Clear-XlsOrphans`(自モジュール起動 PID のみ)」
> 01-design.md §3.1: 起動した PID を `$env:TEMP\xlsagent\<pid>.marker` に記録(finally で削除)。
> → 正常終了したセッションのマーカーは残らない。残っているマーカー = 異常終了の候補。

- 前提タスク: T-03(完了済み。マーカー方式・PID+開始時刻による所有権照合が確立済み)

## 仕様(確定分+実装判断)
- `$env:TEMP\xlsagent\*.marker` を走査。
- 各マーカーの PID について:
  - プロセスが存在しない → マーカーだけ削除(ゴミ掃除)。
  - プロセスが存在し EXCEL.EXE である → 停止して マーカー削除。
  - プロセスが存在するが EXCEL.EXE でない(PID 再利用)→ 停止せずマーカーだけ削除。
- G-10: 全殺し禁止。マーカーにない PID には一切触れない。fail closed(疑わしきは殺さない)。
- マーカーに開始時刻等の照合情報を含める必要があれば、T-03 のマーカー書式を拡張してよい(その場合は Invoke-XlsSession 側の書き込みも合わせて更新し、実装メモに記録)。
- 戻り値: 回収した PID / 掃除したマーカーの一覧(オブジェクト)を返す(エージェントが結果を確認できるように)。

## 受け入れテスト要点(test-plan.md)
- 自 PID のみ回収、他 PID は残す:
  - 死んだ PID のマーカー → マーカーが消える。
  - EXCEL でないプロセスの PID を指すマーカー(例: 自テストが起動した notepad や powershell の PID)→ プロセスは生存のまま、マーカーだけ消える。
  - マーカーのない実行中プロセスには触れない。
  - (可能なら)Invoke-XlsSession の ScriptBlock 実行中に別スレッド/プロセスから見るとマーカーが存在する、正常終了後は消えている(T-03 でテスト済みなら省略可)。
- 「生きた孤児 EXCEL」の再現はリスクがあるため必須としない(強制終了経路は T-02 でテスト済み)。やる場合は安全策を実装メモに書く。
