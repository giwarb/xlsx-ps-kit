# T-07 Get-XlsOverview

## 目的
シート概観の Markdown ダンプ `Get-XlsOverview` を実装する(markitdown 相当。編集計画には使わせない)。

> 01-design.md §3.3:
> ```
> Get-XlsOverview -Path <string> [-Sheet <string[]>] [-MaxRows 50] [-MaxCols 30]
> ```
> - シートごとに `## SheetName` 見出し + Markdown 表。`Range.Text`(表示文字列)ベース。
> - 座標を出さない。SKILL.md で「編集計画には使うな」と書く。
> - `MaxRows/MaxCols` 超過は末尾に `... (N rows × M cols total)` を付ける。

## 入力
- 参照ファイル: docs/01-design.md §3.3、§7(既定 MaxRows/MaxCols は実装中判断)、docs/03-guardrails.md
- 前提タスク: T-06(完了済み)
- 前提レビュー: T-06 系(値変換の罠。ただし Overview は Range.Text ベースなので変換規則は再利用しない点に注意 — 表示文字列をそのまま出す)

## 仕様の具体化
- `-Path` を受けて内部で `Invoke-XlsSession -ReadOnly` を使う(呼び出し側は COM を見ない)。
- 各シートの UsedRange を対象に、`MaxRows`/`MaxCols` でクリップして Markdown 表を生成。
- `Range.Text` は範囲一括で取れない(単一セルずつ)可能性が高い — 設計は「表示文字列ベース」を要求している。性能と正確性のバランスは実装判断(例: 一括 Value2+NumberFormat で近似せず、クリップ後の小さな範囲に限りセル単位 Text を許容する等)。判断を実装メモに記録。
- Markdown 表のセル内のパイプ文字・改行はエスケープ。
- 空シートは `## SheetName` + `(empty)` などの明示。
- 戻り値は文字列(全シート連結)。

## 受け入れテスト要点(test-plan.md)
- `## SheetName` 見出しが出る(複数シート、-Sheet フィルタ)。
- 上限: MaxRows/MaxCols を超えるデータで `... (N rows × M cols total)` の省略表記。
- 表示文字列: 日付セルが表示どおりの文字列で出る(Value2 の生シリアルではない)。
- 座標(A1 等)が出力に含まれない。
- 異常系: 存在しないシート名指定で次の一手が分かる例外。
