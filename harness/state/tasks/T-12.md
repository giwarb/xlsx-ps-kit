# T-12 Test-XlsFormulas.ps1 CLI

## 目的
recalc.py 相当の CLI `skill/scripts/Test-XlsFormulas.ps1` を実装する(P4 完結)。

> 01-design.md §3.6:
> ```
> pwsh -File Test-XlsFormulas.ps1 <path> [timeoutSec=30] [-Force]
> ```
> - 出力: recalc.py 完全互換 JSON(標準出力へ)。
> - 終了コード: `error` キー(Excel 起動失敗・ファイル不在・タイムアウト)のときのみ非 0。`errors_found` / `refused` は 0(G-04)。
> - タイムアウト: `CalculateFullRebuild` を Runspace で走らせて timeoutSec で打ち切り、`{ "error": "timeout" }`。

## 仕様の具体化(実装判断は実装メモに記録)
- 環境注記: この開発機には pwsh(PowerShell 7)が無い。CLI は Windows PowerShell 5.1 の `powershell -File` でも pwsh でも動くこと(G-11 準拠なら自然に満たされる)。テストは powershell.exe で行う。
- 引数: 位置引数 `<path>`、位置引数 `[timeoutSec]`(既定 30)、スイッチ `-Force`。
- スクリプトは XlsAgent.psm1 を相対パスで Import し、Test-XlsFormulas を呼んで JSON を stdout へ 1 個だけ出力する。
- タイムアウト実装: 検証全体(Invoke-XlsSession 含む)を別 Runspace(STA necessity に注意 — Invoke-XlsSession は STA 必須。Runspace の ApartmentState を STA に設定)で実行し、timeoutSec 超過で打ち切り `{ "error": "timeout" }` を出力して非 0 終了。打ち切り時の Excel プロセスは PID マーカー+リースが残るので Clear-XlsOrphans で回収する(実装判断: CLI が自動で回収を試みるか、メッセージで案内するか — 安全性を優先し判断を記録)。
- error 系 JSON: `{ "error": "<説明>" }`(recalc.py 互換。ファイル不在・Excel 起動失敗・タイムアウト等)。exit 1。
- success / errors_found / refused: exit 0。
- stdout には JSON のみ(それ以外のログは stderr か抑制。エージェントがパースする前提)。

## 受け入れテスト要点(02-implementation-plan.md §4)
- errors_found のブックで exit 0 + JSON パース可能 + status="errors_found"。
- success のブックで exit 0。
- refused のブック(T-11 の fixture 手法)で exit 0 + status="refused"。`-Force` で通常フロー。
- ファイル不在で exit 非 0 + `{"error": ...}`。
- タイムアウト: 極端に小さい timeoutSec(例 1 秒未満は不可なら 1)+ 意図的に重いブック、または確実に 1 秒を超える状況で `{"error": "timeout"}` + exit 非 0。重いブックの作成が不安定なら、タイムアウト機構の単体検証(Runspace 打ち切り)で代替してよい(判断を記録)。タイムアウト後に EXCEL.EXE が残らない(または回収手段が機能する)ことを確認。
- stdout が JSON 1 個のみであること(前後に余計な出力がない)。
