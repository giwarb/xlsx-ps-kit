# T-04 Save-XlsWorkbook

## 目的
保存の唯一の経路 `Save-XlsWorkbook` を実装する(G-09: 保存はこの関数のみ)。

> 01-design.md §3.2:
> ```
> Save-XlsWorkbook -Workbook <obj> -Path <string>
> ```
> - 拡張子から `FileFormat` を決定: `.xlsx`→51, `.xlsm`→52, `.xltx`→54, `.xltm`→53, `.csv`→6。
> - 保存前に `Calculation=xlCalculationAutomatic` に戻し `CalculateFullRebuild` を実行(手動のまま保存すると開いた人の環境で古い値が見える)。
> - 上書き時は `DisplayAlerts=$false` 前提で `SaveAs`。既存パスと同一なら `Save`。

## 実装上の注意
- Calculation モード制御(Automatic 復帰 + CalculateFullRebuild)は T-10 の Test-XlsFormulas と共通化する予定(02-implementation-plan.md §5)。内部ヘルパーに切り出してよい。
- .xlsm fixture の作成もテスト内では Invoke-XlsSession 経由で行う(G-06 厳格適用)。マクロ付き fixture はテスト中に VBProject を作れない(Trust 設定依存)ため、「マクロなし .xlsm でも FileFormat 52 で保存され HasVBProject が false のまま拡張子と形式が一致する」ことの検証+既存 .xlsm があれば HasVBProject 維持、という2段構えでよい。工夫と判断は実装メモに書くこと。
