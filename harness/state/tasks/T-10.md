# T-10 Test-XlsFormulas 関数

## 目的
recalc.py 互換の数式検証関数 `Test-XlsFormulas` を実装する(P4 検証系の中核)。
CLI ラッパー(T-12)と外部リンク refused(T-11)は後続タスク。本タスクは関数本体のみ。

> 01-design.md §3.6:
> - `Invoke-XlsSession -ReadOnly` で開き `CalculateFullRebuild`(`Calculation` は Automatic に一時変更)。
> - 全シートで `SpecialCells(xlCellTypeFormulas, xlErrors)`。ヒットなし例外は握りつぶす。
> - 出力 JSON(recalc.py 完全互換):
>   ```
>   { "status": "success" | "errors_found",
>     "total_formulas": int,
>     "total_errors": int,
>     "error_summary": { "#REF!": { "count": int, "locations": ["Sheet1!B5", ...], "locations_truncated": int }, ... } }
>   ```
> - G-04: キー名を変えない。locations は 100 件で切り、locations_truncated に切った数。

## 仕様の具体化(実装判断は実装メモに記録)
- 関数シグネチャ: `Test-XlsFormulas -Path <string>`(戻り値は PSCustomObject。JSON 文字列化は T-12 の CLI 側でも使うので -AsJson スイッチを付けるかは実装判断)。
- ReadOnly で開いて CalculateFullRebuild する(ファイルは変更しない — 検証専用)。
- total_formulas: 全シートの数式セル総数(SpecialCells(xlCellTypeFormulas) の Areas 集計。T-08 の Get-XlsFormulaCellKeySet 的手法を再利用してよい)。
- エラー検出: `SpecialCells(xlCellTypeFormulas, xlErrors)`(第2引数 xlErrors=16)。エラー種別は各セルの Value2(Int32 エラーコード → $script:Xl の既存定数で "#REF!" 等へ。T-06 の変換を再利用)。
- error_summary: エラー種別ごとに count / locations(`Sheet1!B5` 形式、$ なし) / locations_truncated。locations は 100 件で切る。
- locations の順序: シート順→セル順(決定的であること。テストで固定)。
- status: total_errors -eq 0 なら "success"、それ以外 "errors_found"。
- 外部リンクの refused 判定は T-11 なので今回は実装しない(構造だけ意識)。
- 数式ゼロのブック: total_formulas=0, status="success"。

## 受け入れテスト要点(02-implementation-plan.md §4)
- 意図的に `#REF!` `#DIV/0!` `#NAME?` を含むブック(Invoke-XlsSession 内で作成、Save-XlsWorkbook 経由保存)で、種別ごとの count と locations が正しい。
- 101 個以上のエラーで locations が 100 で切れ locations_truncated が正しい(1 セルずつ 101 個の数式を書くのではなく、Set-XlsRange か数式の一括代入で効率的に作る — G-08 に注意: Formula の一括代入は Value2 と別なので、範囲への同一数式一括代入 `$range.Formula = '=1/0'` が使える。実機確認して実装メモに記録)。
- 数式はあるがエラーなし → status="success"、total_formulas > 0、error_summary が空。
- 数式ゼロ → success / 0 / 0。
- Manual のまま古い値が残ったブックでも CalculateFullRebuild 後の値で判定される(T-04 の罠 5 を利用したテスト)。
- 異常系: ファイル不在で次の一手が分かる例外。
