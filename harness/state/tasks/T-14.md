# T-14 patterns.md(実行確認済み COM スニペット集)

## 目的
`skill/reference/patterns.md` を、スキル利用エージェントが Invoke-XlsSession の ScriptBlock 内に
そのまま貼って使える「実行確認済みスニペット集」として完成させる。

> 01-design.md §6: ヘッダー行書式/テーブル化(ListObjects.Add)/列幅自動調整/コメント追加(AddComment と
> AddCommentThreaded の両方)/条件付き書式/データ検証/グラフ挿入/名前定義/シート追加・複製・削除。各 5〜10 行。

## 入力
- 参照ファイル: docs/01-design.md §6、docs/03-guardrails.md G-12
- 前提タスク: T-13(完了済み。定数実測は再利用可)
- 前提レビュー: T-13 系(公式列挙名と実測値の区別、一般化しすぎない記述)

## 作業内容
- 9 パターンそれぞれについて:
  1. `param($app, $wb)` の ScriptBlock 内で動く 5〜10 行のスニペットを書く。
  2. 実際に Invoke-XlsSession で実行し、期待どおり動くことを確認(使い捨てスクリプト。保存が要る場合は Save-XlsWorkbook 経由)。
  3. patterns.md に「何をするか 1 行 + スニペット + 実行確認の 1 行(日付・確認した結果)」の形で載せる。
- 定数はマジックナンバー直書きでよいが、コメントで定数名を併記(com-constants.md と相互参照)。
- AddCommentThreaded は Excel のバージョンによっては使えない可能性がある。使えない場合はその事実を実測して明記(「この環境の Excel ビルド X では動作/エラー Y」)— それも有益な reference になる。
- G-12: 実行して確認できたスニペットだけを載せる。動かなかったものは「動かなかった」事実ごと記録するか、載せない。
- モジュール(.psm1)は変更しない想定。変更しない限り Pester 回帰は不要。
- 実測はフォアグラウンドのみ。run_in_background / Monitor 禁止。EXCEL.EXE を残さない。
